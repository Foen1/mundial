# Mundial, Tecnología y Sociedad

Creador: Ángel Cabrera

## Cómo usar
1. Descomprime la carpeta.
2. Abre `index.html` en el navegador.
3. Mantén todos los archivos en la misma carpeta para que funcionen los enlaces, estilos y JavaScript.

## Archivos incluidos
- index.html
- historia.html
- inversion.html
- economia.html
- derechos.html
- seguridad.html
- ia.html
- beneficios.html
- style.css
- script.js
